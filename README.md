# BLACKWOOD — Traducción al Español de España (es-ES)

Traducción **no oficial** de **BLACKWOOD** al español de España, realizada por **Parca Griega**.

> **Versión actual:** v1.0.3  
> **Plataforma:** Windows / Steam  
> **Idioma:** Español de España (es-ES)

## Descargar

La descarga pública se distribuirá desde **GitHub Releases**:

**[Ir a la última versión](../../releases/latest)**

Archivo recomendado:

`BLACKWOOD_Traduccion_ES-ES_ParcaGriega_v1.0.3_EXE_PUBLICA.zip`

## Qué está traducido

La prioridad es que todo lo necesario para jugar y entender BLACKWOOD esté en español:

- Menús y ajustes
- HUD e interfaz
- Objetivos y misiones
- Subtítulos y diálogos
- Tutoriales, avisos y botones
- Tienda, inventario, ropa, dinero y otros elementos funcionales

Algunos carteles, pósteres, anuncios y gráficos puramente decorativos pueden permanecer en inglés.

## Instalación

1. Cierra **BLACKWOOD** completamente.
2. Descarga y descomprime el ZIP de la última Release.
3. Ejecuta `BLACKWOOD_Traduccion_ES-ES_ParcaGriega_v1.0.3.exe`.
4. Comprueba que la carpeta mostrada sea la instalación de BLACKWOOD.
5. Mantén activada la **copia de seguridad**.
6. Pulsa **Instalar / reinstalar**.
7. Espera al mensaje de instalación completada.
8. Abre BLACKWOOD.

## Desinstalación

1. Cierra BLACKWOOD.
2. Ejecuta el mismo instalador.
3. Pulsa **Desinstalar traducción**.
4. Confirma la operación.

## Windows SmartScreen

El instalador no está firmado con un certificado comercial de firma de código. Por ese motivo, Windows SmartScreen o algunos antivirus pueden mostrar una advertencia.

Comprueba siempre el SHA-256 publicado en este repositorio y en la Release antes de ejecutar el archivo.

## Actualizaciones de Steam

Una actualización, reparación o verificación de archivos de BLACKWOOD puede sustituir archivos traducidos. Si ocurre, vuelve a ejecutar el instalador.

Si una futura actualización modifica la estructura interna del juego, puede ser necesaria una nueva versión de la traducción.

## Reportar un problema

Si encuentras texto funcional sin traducir o un error:

1. Indica la versión de la traducción.
2. Indica dónde aparece el problema.
3. Adjunta una captura o vídeo.
4. Si el instalador falla, conserva el diagnóstico generado en la carpeta del juego.

Puedes abrir un **Issue** en este repositorio usando la plantilla preparada.
